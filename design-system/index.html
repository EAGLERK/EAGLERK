MyMoney design system

Written from the running app, not for it: every value below comes from src/styles.css, src/motion/index.ts or a measurement of the real elements (design-system/measured.json, 2026-11-06). Source of truth: design-system/tokens.json. Rebuild this page with npm run design:build; tests/tokens.test.ts fails if the tokens and the stylesheet disagree.

Direction. Calm, neutral, trustworthy. One accent (mint green) that means "do this" and "this is on"; status colours that always come with a word or icon; hairline borders and small shadows; the system font; 44px touch targets; one primary button per screen.
